# Security Policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities through public GitHub issues.

Report them privately through:

https://maradigma.com/contacto/

Include the affected plugin version, the WordPress and PHP versions, reproduction
steps, and the expected security impact. Do not include production credentials,
customer information, payment data, or other personal data.

Maradigma will acknowledge the report, investigate it, and coordinate remediation
and disclosure when applicable.

## Supported versions

Security fixes are provided for the latest published version of the plugin.
